# 工作日志 · 层级重构 spec（v0.2）

状态：已批准，实施中
范围：只改渲染层与「阶段」相关逻辑，不改已写入的记录格式。

## 1. 背景

当前甘特是三层：**会话 → 阶段 → 主题**。其中：

- 「会话」来自 `sessionId`，回答*在哪发生*；
- 「主题」来自每轮摘要的 `topicId`，回答*在做什么*；
- 「阶段」**不是数据**，是渲染时按「相邻轮次间隔 ≤ 10 分钟」现算的时间块，没有 id、没有名字。

问题：

1. 阶段没有身份，却占了层级中间，用户无法命名/引用/合并它；
2. 同一主题被切成多段会变成**多个同名阶段行**（实测一天内「插件发布可行性评估」出现 3 次）；
3. 两个正交维度（会话=位置、主题=主语）被排成父子链，和「按主题」视图方向相反；
4. 行数膨胀：工作日志会话 7 个主题渲染成 16 行，参考项目 14 个主题渲染成 19 行。

## 2. 结论：删掉阶段，只保留两层

```
按会话：  会话 → 主题（一行一主题，多段色条）
按主题：  主题 → 轮次（跨会话，已有的另一张视图）
```

- **会话**：过滤维度（在哪发生），可折叠。
- **主题**：唯一语义实体（在做什么）。
- **片段**：主题色条上的断开处，纯视觉，不是层级。
- **时间刻度**：小时/分钟刻度线，帮助定位时间，不产生节点。

阶段的三个职责分别由：主题名（概括）、色条断开（时间连续）、刻度线（定位）接管。

## 3. 渲染规则

1. 每个会话下，**一行一个主题**，按首次出现时间排序。
2. 一个主题在时间上不连续时，画**多段色条**；相邻片段间隔小于 `mergeGapMinutes` 时合并为一段显示（避免碎成点）。
3. 主题行显示：主题名（超长省略，悬浮看全文）、条数/时长。
4. 会话行显示：会话标题 + 主题数，可折叠。
5. 悬浮卡：主题名、片段数、合计时长、最近两条轮次摘要。
6. 「现在」线、时间轴、底部统计保持不变。

## 4. 配置变更

| 配置 | 变更 |
| --- | --- |
| `mergeGapMinutes` | 语义改为「相邻片段合并阈值」：同一主题的两段之间间隔小于该值，画成一整段。默认 10，0 表示不合并（每轮一段）。不再影响行数。 |

## 5. 代码变更点

- `lib/client.js`：删除 `block.stages`、`openStages`、`stageOpen`、`toggleStage`、`stageTip`、`topicTipInRow`；渲染直接遍历 `block.topics`，片段按阈值合并。
- `mobile.js`：删除 `withBlocks`（模板从未使用该字段），卡片保持平铺。
- `lib/fold.js`、`foldTopicBlocks` 导出：不再使用，删除。
- 自测：删除折叠相关用例；新增「每个主题一行」「同名主题不会出现多行」「片段合并阈值生效」断言。

## 6. 验收标准

1. 工作日志会话：7 个主题 → **7 行**（不含会话行）。
2. 参考项目会话：14 个主题 → **14 行**。
3. 不再出现同名主题重复成多行。
4. 甘特冒烟脚本渲染通过，且每个主题行都有文字。
5. Pocket 页 15/15，自测全过。

## 7. 移动端甘特（本次同步支持）

目标：在 Pocket 页面（手机浏览器）也能看到当日的甘特，与面板**同一数据、同一规则**，但不要求与面板像素一致。

### 7.1 布局

- 顶部一条 24 小时时间轴，**不横向滚动**：整日宽度铺满屏幕；
- 每行一个主题：左侧 88px 固定标签列（主题名，超长省略），右侧为轨道；
- 行高 18px，色条 8px；会话用 12px 小标题分组，之间留 6px；
- 刻度每 3 小时一条淡竖线，标注 `00 06 12 18 24`；
- 「现在」位置画一条虚线。

### 7.2 规则

1. 一行一个主题，**没有阶段层**（与桌面一致）；
2. 同一主题的多段用多段色条表示，间隔小于 `mergeGapMinutes` 的相邻片段合并为一段；
3. 只渲染有主题的记录；无主题的轮次仍留在下方卡片列表里；
4. 宽度全部用百分比，375px 与 430px 都必须可用；
5. 纯服务端渲染，不依赖额外 JS 请求。

### 7.3 交互

- 点击色条：滚动到下方对应的卡片，并短暂高亮；
- 点击标签：无动作（避免误触）；
- 手机端不提供折叠，主题通常 ≤ 10 行。

### 7.4 验收

1. `/dsh-worklog/mobile` 页面含 `data-gantt` 区域，行数等于当日主题数；
2. 每行至少有一个色条，条宽 > 0 且不超出轨道；
3. 375px 宽下无横向滚动（`overflow-x: hidden` 且轨道用百分比）；
4. 现有 15 项结构检查仍全过。
